Começar agora
01

Prepare o computador

Esta parte é feita uma vez. Depois, iniciar o projeto será bem mais curto.

O projeto não é um único arquivo: Python executa a API e Node.js executa as duas interfaces React. O VS Code permite manter tudo organizado em uma pasta e em três terminais.

Py

Python 3.12

Executa o FastAPI, o banco SQLite e a integração com o Gemini. Durante a instalação, marque Add Python to PATH.

N

Node.js LTS

Inclui o comando npm, usado para instalar e iniciar o site e o painel.

V

Visual Studio Code

Será usado para abrir a pasta, editar o arquivo .env e manter os terminais visíveis.

Como conferir: abra o Prompt de Comando e execute python --version, node --version e code --version. Se os três mostrarem uma versão, está pronto.

Baixe a versão correta

  1. Acesse o repositório ou baixe diretamente o ZIP da tag v3.9.0.
  2. Extraia o ZIP. Não execute o projeto de dentro da janela do arquivo compactado.
  3. Renomeie a pasta, se desejar, para analise-pele-V3.
  4. No VS Code, escolha File → Open Folder e selecione essa pasta.
Baixar v3.9.0 Ver código no GitHub
Você deve ver na raiz: pastas admin, frontend, routers e arquivos como main.py e requirements.txt. Se o VS Code mostrar apenas outra pasta com o mesmo nome, abra essa pasta interna.
02

Inicie a API

Ela recebe os pedidos das interfaces, acessa a IA, consulta o banco e devolve respostas.

1

Abra o primeiro terminal

No VS Code, use o menu Terminal → New Terminal ou pressione Ctrl + `. Confira se o caminho mostrado termina na pasta raiz do projeto.

2

Crie o ambiente virtual

A pasta .venv separa as bibliotecas deste projeto das demais instalações do computador.

CMD • raiz do projeto
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt

Quando a ativação funcionar, (.venv) aparecerá antes do caminho no terminal. A instalação pode demorar alguns minutos.

3

Crie e configure o arquivo privado

CMD • raiz do projeto
copy .env.example .env

No explorador lateral do VS Code, abra .env. Para usar análises por texto e foto, coloque uma chave válida do Google AI Studio após o sinal de igual:

.env — exemplo local da v3.9
GEMINI_API_KEY=cole_sua_chave_real_aqui
GEMINI_MODEL=gemini-3.5-flash-lite
APP_ENV=development
DATABASE_PATH=produtos.db
CORS_ORIGINS=http://localhost:5173,http://localhost:5174
Nunca compartilhe o arquivo .env. A chave fica somente no backend. Não coloque a chave em arquivos da pasta frontend ou em código JavaScript.
4

Crie o banco e carregue a demonstração

CMD • ambiente virtual ativo
python criar_banco.py
python popular_catalogo.py --aplicar

O primeiro comando cria as tabelas. O segundo adiciona o catálogo fictício da Lumina. Execute a carga apenas quando quiser essa demonstração; um projeto próprio pode começar com banco vazio.

5

Ligue a API

CMD • mantenha este terminal aberto
uvicorn main:app --reload

Quando aparecer Uvicorn running on http://127.0.0.1:8000, segure Ctrl e clique no endereço. Para ver e testar as rotas, abra http://127.0.0.1:8000/docs.

03

Inicie o site público

A interface Lumina conversa com a API que já está rodando na porta 8000.

Não escreva novos comandos no terminal da API. Clique no símbolo + do painel de terminais do VS Code para abrir um segundo terminal.

Terminal 2 • site público
cd frontend
npm install
copy .env.example .env
npm run dev

O arquivo criado deve conter:

frontend\.env
VITE_API_URL=http://127.0.0.1:8000
Abra pelo link certo: o terminal do Vite exibirá algo como Local: http://localhost:5173/. Segure Ctrl e clique nesse endereço. O número pode mudar se a porta já estiver em uso; use sempre o link realmente mostrado.

O comando npm install é necessário apenas na primeira instalação ou quando as dependências mudarem. npm run dev é o comando que liga o site.

04

Inicie o painel de produtos

Na v3.9, o painel é local e abre no navegador como uma segunda aplicação.

Abra um terceiro terminal. Como os novos terminais normalmente começam na raiz, execute:

Terminal 3 • painel administrativo
cd admin
npm install
copy .env.example .env
npm run dev

O arquivo de ambiente do painel também deve apontar para a API local:

admin\.env
VITE_API_URL=http://127.0.0.1:8000
A

O que ele faz

Cadastra, edita, filtra, ativa e desativa produtos; também envia imagens para o backend.

!

O que ele não é

Não é um painel público protegido por login. Use esta edição apenas localmente.

Se o site já ocupou a porta 5173, o Vite provavelmente exibirá http://localhost:5174/. Use o endereço mostrado no terminal.

05

Teste sem adivinhar

Use esta ordem para identificar rapidamente em qual parte está um possível problema.

1. Perfil manualProva que site, API, banco e recomendações se comunicam sem depender da IA.
2. TextoProva que a chave Gemini e a análise textual estão funcionando.
3. FotoProva o upload, processamento visual e resposta da IA.

06

Como abrir nas próximas vezes

Você não precisa reinstalar tudo. Apenas ligue cada parte novamente.

Na raiz do projeto:

Terminal 1
.venv\Scripts\activate
uvicorn main:app --reload

Em outro terminal, a partir da raiz:

Terminal 2
cd frontend
npm run dev

Em outro terminal, a partir da raiz:

Terminal 3
cd admin
npm run dev

Para desligar, clique em cada terminal e pressione Ctrl + C. Fechar o navegador não desliga os servidores.

?

Erros mais comuns

Abra somente o item que corresponde ao que apareceu na sua tela.

“python” ou “npm” não é reconhecido
O programa não está instalado ou não foi adicionado ao PATH. Reinstale Python marcando Add Python to PATH e instale a versão LTS do Node.js. Depois feche e abra novamente o VS Code.
Aparece “No module named ...”
Ative a .venv e reinstale as dependências com python -m pip install -r requirements.txt. Confira também se o terminal está na raiz.
A API abre, mas texto e foto retornam erro 503
Catálogo e perfil manual funcionam sem IA, mas texto e foto exigem uma GEMINI_API_KEY válida no .env. Após corrigir, pare e reinicie o Uvicorn.
O site diz que não conseguiu conectar
Confirme se a API continua aberta na porta 8000 e se frontend\.env contém exatamente VITE_API_URL=http://127.0.0.1:8000. Reinicie o Vite depois de alterar o arquivo.
O painel ou o site foi para outra porta
Isso é normal quando 5173 já está ocupada. Abra o link que o Vite mostrou. Se houver bloqueio de CORS, acrescente a origem à variável CORS_ORIGINS do backend e reinicie a API.
Não aparecem produtos recomendados
O produto precisa estar ativo, ter estoque maior que zero e ser compatível com o perfil. Para a demonstração pronta, confirme que executou python popular_catalogo.py --aplicar.
A foto funciona uma vez e falha em outra
Hospedagem gratuita e provedor de IA podem oscilar. Mantenha a página aberta, use imagem até 5 MB em JPG/PNG/WEBP e tente novamente. Se o perfil manual funciona, a conexão básica com a API está correta.
