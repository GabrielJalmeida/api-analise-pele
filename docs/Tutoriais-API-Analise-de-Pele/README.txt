TUTORIAIS — API DE ANÁLISE DE PELE
=================================

Este pacote funciona offline e não precisa ser instalado.

COMO ABRIR
1. Extraia todo o arquivo ZIP para uma pasta.
2. Dê dois cliques em LEIA-ME.html.
3. Escolha um dos dois tutoriais.

Também é possível abrir diretamente o index.html existente em cada pasta:

01-lumina-v3.9\index.html
02-integrar-api\index.html
O segundo tutorial contém ainda uma demonstração adaptável em:

02-integrar-api\exemplo-integracao\index.html

IMPORTANTE
- Os tutoriais podem ser lidos sem internet.
- Links externos e chamadas reais à API exigem conexão.
- Nunca coloque chaves de IA em HTML, CSS ou JavaScript do navegador.
- As marcações de progresso ficam salvas somente neste navegador.

Versão do material: 1.0 — agosto de 2026
